# Last Stand: Survival ☠️

An arcade arena survival game with enemy waves, upgrades, medkits, and a saved high score.

## Play

Open `index.html` in a browser, or enable GitHub Pages in **Settings → Pages** and choose the `main` branch / root folder.

## Controls
- WASD or arrow keys: move
- Aim with the mouse and hold click to shoot
- Collect green medkits and gold upgrades

How long can you survive?
